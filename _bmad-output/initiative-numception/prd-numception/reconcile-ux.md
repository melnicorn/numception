# Reconcile: UX spines → PRD

The PRD memlog decisions (2026-10-09) take precedence: daily streak IN, the same stats captured for kid and adult, telemetry relaxed (first-party upload, no ad SDKs), no paywall in POC, Normal unlocks for kids with a softer cue. Where the PRD follows one of these, it is listed under "UX docs to update", not as a gap. Items already present in substance are not listed. These include player causality, geometry is the HUD, no end screens, power-cut rules, soft miss, parent gate, Kid-absent social, flashing, colour-independence, tap targets for cells, save and resume, and offline.
